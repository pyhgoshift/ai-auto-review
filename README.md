# AI끼리 파일을 주고받으며 코드를 검토하는 방법

## 1. 왜 이 방법이 필요한가요?
인공지능(AI) 혼자서 코딩을 하다 보면 가끔 엉뚱한 코드를 짜거나 실수를 할 때가 있습니다. 이때 다른 똑똑한 AI에게 "내가 짠 코드 좀 확인해줘"라고 부탁하면 실수를 줄이고 훨씬 완벽한 결과물을 만들 수 있습니다. 

우리는 복잡한 통신 기술 없이, 단순한 **'마크다운 파일(.md)'**을 활용해 AI끼리 서로 묻고 답하며 코드를 검토하는 아주 쉽고 확실한 방법을 만들었습니다. 다른 프로젝트에서도 누구나 똑같이 따라 할 수 있습니다.

---

## 2. 어떻게 준비하나요? (폴더 만들기)
내 프로젝트 폴더 안에 AI끼리 대화할 우체통 역할을 할 폴더 2개를 만들어 둡니다.

*   **요청하기 (requests)** : 검토를 부탁할 질문 파일을 넣는 폴더입니다.
*   **결과받기 (audits)** : 검토가 끝난 답변 파일을 받는 폴더입니다.

---

## 3. 따라 해보기 (스텝바이스텝 가이드)

지금은 사람이 중간에서 우체부 역할을 해주는 안전한 방식을 사용합니다. 아래 순서대로 따라 해보세요.

### 1단계: 검토 요청서 만들기
작업 중이던 AI가 코딩을 하다가 막히거나 확인이 필요할 때, AI에게 이렇게 지시합니다.
> "지금 고민 중인 문제와 코드를 정리해서 `요청하기/오늘날짜-질문.md` 파일로 만들어줘."

**[매우 중요한 팁]** AI가 질문 파일을 만들 때, 문서 맨 아래에 반드시 다음 문장을 적도록 시켜야 합니다.
> *"당신의 검토 결과는 반드시 `결과받기/오늘날짜-답변.md` 파일로 만들어서 저장해 주세요."*

### 2단계: 다른 AI에게 파일 전달하기 (사람이 직접)
1. 만들어진 `요청하기/오늘날짜-질문.md` 파일을 엽니다.
2. 내용을 모두 복사합니다.
3. 코드 검토를 잘하는 다른 AI(예: CodeX, Claude 등)의 채팅창에 그대로 붙여넣고 질문을 보냅니다.

### 3단계: 검토 결과 파일 받기
질문을 받은 다른 AI가 코드를 분석한 뒤, 1단계에서 지시한 규칙을 잘 지켜서 `결과받기/오늘날짜-답변.md`라는 파일로 답변을 작성해 줍니다. (만약 파일을 만들지 않고 말로만 답변한다면, 파일로 저장해 달라고 한 번 더 요구하세요.)

### 4단계: 원래 AI에게 알려주기
이제 원래 코딩을 하던 AI에게 이렇게 말해줍니다.
> "`결과받기/오늘날짜-답변.md` 파일에 다른 AI의 훌륭한 조언이 도착했어. 이 파일을 읽어보고 코드를 수정해줘."

원래 AI가 조언을 읽어보고 스스로 코드를 완벽하게 고치게 됩니다!

---

## 4. 앞으로의 목표: 사람 없이 완전 자동화하기!

위에서 해본 방법은 아주 훌륭하지만 사람이 중간에서 파일을 전달해 주어야 합니다. 앞으로는 이 과정마저 컴퓨터가 알아서 하도록 프로그램을 개발하는 것이 우리의 목표입니다.

*   **자동 감시 프로그램 개발**: `요청하기` 폴더에 새 파일이 생기는지 계속 지켜보다가, 파일이 생기면 곧바로 다른 AI에게 자동으로 질문을 보내주는 감시 프로그램을 만들 수 있습니다.
*   **자동 깨우기**: 다른 AI가 답변을 `결과받기` 폴더에 작성하면, 자고 있던 원래 AI를 프로그램이 톡톡 깨워서 "답변 왔으니 다시 일해!"라고 알려주는 기능을 추가합니다.

이런 자동화 프로그램만 하나 개발해 두면, 앞으로는 **사람이 전혀 개입하지 않아도 AI들끼리 알아서 질문하고, 검토받고, 코드를 고치는 마법 같은 시스템**이 완성됩니다.

## 5. 지금 바로 내 PC에서 사용해보기 (퀵스타트 가이드)

윈도우 PC를 켜고 키보드로 명령어 창(명령 프롬프트나 파워쉘)을 연 뒤, 아래 순서대로 그대로 입력하시면 됩니다.

### 1단계: 깃허브에서 내 PC로 폴더 다운받기
원하는 드라이브(예: `D:\>`)에서 아래 명령어를 쳐서 저장소를 다운로드 받습니다.
```cmd
git clone https://github.com/pyhgoshift/ai-auto-review.git
```
다운로드가 끝나면, 새로 생긴 폴더 안으로 들어갑니다.
```cmd
cd ai-auto-review
```

### 2단계: 파이썬 감시 프로그램 준비하기
감시 프로그램이 폴더를 실시간으로 쳐다보게 하려면 파이썬 부품(`watchdog`)이 하나 필요합니다.
```cmd
pip install watchdog
```

### 3단계: 감시 프로그램 켜기
이제 준비가 끝났습니다! 감시 프로그램을 실행합니다.
```cmd
python scripts/자동감시_프로그램.py
```
명령어를 치면 까만 화면에 **"🤖 A2A-FAAP 자동화 감시 프로그램 시작됨..."** 이라는 글자가 뜨고 프로그램이 폴더를 지켜보기 시작합니다. (이 까만 창은 끄지 말고 그대로 두세요!)

---

### 4단계: 진짜로 마법이 일어나는지 확인해 보기! (직접 해보기)

1. **폴더 열기**: 윈도우 [내 PC]나 [탐색기]를 열고 `ai-auto-review\.a2a\requests` 폴더로 찾아 들어갑니다. (이 폴더가 바로 '요청하기' 폴더입니다.)
2. **파일 던져넣기**: 그 폴더 안에 메모장이나 에디터를 열고 아무 글이나 쓴 뒤, 파일 이름을 **`내코드질문.md`** 라고 저장해 보세요.
3. **마법 확인하기**: 파일을 저장하는 순간! 아까 켜둔 까만 화면(명령어 창)을 쳐다보세요. 
   - *"👀 새로운 질문 파일 발견!"* 
   - *"🚀 다른 AI에게 질문 전달 중..."* 이라는 글자가 뜹니다.
4. **결과 받기**: 2초 뒤, `.a2a\audits` (결과받기) 폴더에 들어가 보세요. 방금 전까지 없었던 **`내코드답변.md`** 파일이 자동으로 딱! 만들어져 있을 것입니다.

---

### 💡 인공지능(AI)은 이걸 어떻게 쓰나요?
이 폴더 안에는 이미 인공지능을 위한 **'스킬 파일'**(`.agents/skills/ai-reviewer/SKILL.md`)이 들어있습니다. 
앞으로 Antigravity 같은 인공지능 채팅창에서 이 폴더(`ai-auto-review`)를 열고 이렇게만 말씀하시면 됩니다.

> **"ai-reviewer 스킬을 켜고, 요청하기 폴더에 있는 코드 좀 검토해줘!"**

그러면 인공지능이 알아서 스킬 규칙을 읽고, 깐깐하게 검토한 뒤 결과받기 폴더에 마크다운 파일로 정답을 쏙 넣어드리게 됩니다.
