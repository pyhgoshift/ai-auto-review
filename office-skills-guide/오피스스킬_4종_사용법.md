> 전제: **Claude Code**(터미널 AI) 기준. 일반 채팅창은 파일을 만들 수 없어 해당 없음

## 0. 공통: 스킬이 "설치됐다"는 뜻

```
프로젝트폴더\
 └─ .claude\
     └─ skills\
         ├─ office-agent\SKILL.md
         ├─ office-productivity\SKILL.md
         ├─ officecli\SKILL.md
         └─ office-docs\SKILL.md   (+ scripts\ 폴더)
```
- Claude Code는 시작할 때 각 SKILL.md 맨 위의 `description`만 읽어 둡니다.
- 요청이 description과 맞으면 본문을 펼쳐 그대로 따릅니다.
- **확실하게 쓰려면 이름을 불러 주세요:** "office-agent 스킬로 …"
- 설치 확인: Claude Code에 "지금 쓸 수 있는 스킬 목록 보여 줘"라고 물어보기

**모든 스킬 공통 준비물 (윈도우)**
| 준비물 | 용도 | 확인 명령 |
|---|---|---|
| Python 3.10 이상 또는 `uv` | 문서를 만드는 코드 실행 | `uv --version` |
| LibreOffice | 만든 문서를 PDF로 바꿔 **눈으로 확인** | `soffice --version` |
| 한글 글꼴 (맑은 고딕) | 한글 깨짐 방지 | 윈도우 기본 탑재 |

## 1. Office Agent — "하나로 다 하는" 종합 스킬 ★추천

### 추가 설치 (SKILL.md만으로는 안 됨)
1. 원본 저장소 `office-agent-skills` 전체를 받기 (스크립트·스타일 파일이 들어 있음)
2. 저장소의 **설치 스크립트를 한 번 실행** → `.venv`(전용 파이썬 환경) 생성
3. LibreOffice, Poppler(PDF→그림), qpdf(PDF 검사), pandoc(문서 읽기), Node.js(PPT 생성용) 설치
4. 스킬은 `<저장소>\.venv\Scripts\python.exe`만 쓰도록 되어 있음. 없으면 **멈추고 설치하라고 안내함**

### 4가지 작업 방식 (스킬이 자동으로 고름)
| 방식 | 언제 | 예시 요청 |
|---|---|---|
| **템플릿** | 기관 서식 파일이 있을 때 (1순위) | "`주간보고_서식.docx`의 {{기준일}}, {{진척률}} 자리를 채워 줘" |
| **테마** | 서식은 없고 색·글꼴만 맞출 때 | "corporate-blue 테마로 보고서 만들어 줘" |
| **새로 만들기** | 아무 조건 없을 때 | "주간보고 워드 새로 만들어 줘" |
| **수정** | 기존 파일 일부만 고칠 때 | "3번 표의 상태 열만 고쳐 줘, 나머지는 그대로" |

### 형식별 사용 예
**워드 (서식 채우기)**
```
office-agent 스킬로 C:\PMO\서식\주간보고_서식.docx 를 템플릿 모드로 채워 줘.
값: 기준일=2026-11-19, 진척률_계획=88, 진척률_실적=78
결과는 outputs\주간보고_1119\ 에 저장하고 PDF로 렌더링해서 확인해.
```
→ 내부 동작: `replace-docx-placeholders.py` 실행 → 검증 → PDF 변환 → 결과 경로 보고
⚠️ 머리글·바닥글·글상자 안의 `{{ }}`는 못 바꿀 수 있음(스킬이 직접 경고). 반드시 PDF로 확인.

**엑셀 (셀 지정 채우기)**
```
office-agent 스킬로 이슈대장_서식.xlsx 를 채워 줘.
매핑: 이슈!B2=연계 API 규격 지연, 이슈!C2=높음, 이슈!D2=11/12
수식은 값으로 바꾸지 말고 수식으로 남겨. 다 만들면 수식 결과를 검증해.
```
→ `populate-xlsx-template.py` + 매핑 JSON 사용. **매크로 파일(.xlsm)도 보존**.

**PPT**
```
office-agent 스킬로 주간보고 내용을 5장짜리 발표자료로 만들어 줘.
1장 표지, 2장 진척률, 3장 이슈, 4장 리스크, 5장 다음 주 계획.
만든 뒤 슬라이드를 그림으로 렌더링해서 글자 넘침이 없는지 확인해.
```

**PDF**
```
office-agent 스킬로 outputs 폴더의 PDF 3개를 하나로 합치고 텍스트가 정상인지 확인해.
```

### 좋은 점 (원문 규칙)
- 원본 파일을 **절대 덮어쓰지 않음**, 결과는 `outputs\작업명\`에
- 문서 안의 **매크로·스크립트는 실행하지 않음** (문서를 신뢰하지 않는 입력으로 취급)
- 검증 도구가 없으면 **"검증했다"고 거짓 보고하지 않음**

## 2. Office Productivity — 혼자서는 "목차"

### 정체
문서·엑셀·PPT·변환 작업을 **7단계로 나눈 안내서**입니다. 각 단계에서 **다른 스킬을 부르라고** 적혀 있습니다.

| 단계 | 불러야 하는 스킬 (각각 따로 설치 필요) |
|---|---|
| 문서 | `libreoffice-writer`, `docx-official`, `pdf-official` |
| 엑셀 | `libreoffice-calc`, `xlsx-official`, `googlesheets-automation` |
| PPT | `libreoffice-impress`, `pptx-official`, `frontend-slides`, `nanobanana-ppt-skills` |
| 변환 | `libreoffice-writer`, `libreoffice-calc`, `pdf-official` |
| 자동화 | `workflow-automation`, `file-organizer` |
| 그림 | `libreoffice-draw`, `canvas-design`, `mermaid-expert` |
| DB | `libreoffice-base`, `database-architect` |

### 쓰는 법
- 위 스킬들이 **실제로 설치돼 있어야** 의미가 있습니다. 없으면 AI가 "@docx-official을 쓰라는데 없다"고 하거나, **아는 척 비슷하게 흉내** 냅니다.
- 원문에 있는 "복사해서 쓰는 프롬프트" 예: `Use @docx-official to create Word documents`
- **Claude 사용자라면:** Claude에 내장된 docx·xlsx·pptx·pdf 스킬이 이 역할을 대신하므로 **이 스킬은 건너뛰어도 됩니다.**

## 3. OfficeCLI — 명령어 한 줄로 문서 조작

### 추가 설치
- 별도 프로그램 `officecli`를 받아야 함 (원문 설치 명령은 **맥(M 시리즈)용**. 윈도우는 해당 릴리스에서 윈도우용 파일을 받아야 함)
- `officecli mcp claude` → Claude가 도구로 직접 호출할 수 있게 등록
- 확인: `officecli --version`

### 핵심 명령 (AI가 대신 실행하지만, 알아 두면 결과를 이해하기 쉬움)
| 명령 | 하는 일 |
|---|---|
| `officecli create 보고서.docx` | 빈 문서 만들기 |
| `officecli view 보고서.docx outline` | 구조만 보기 (토큰 절약) |
| `officecli add 보고서.docx /body --type paragraph --prop text="..."` | 문단 추가 |
| `officecli set 이슈.xlsx 'Sheet1!C2' --prop formula="=COUNTIF(D:D,\"열림\")"` | 셀에 수식 |
| `officecli merge 서식.docx 결과.docx '{"기준일":"2026-11-19"}'` | **서식 채우기 (가장 유용)** |
| `officecli batch 보고서.docx --input 작업목록.json` | 여러 작업 한 번에 |
| `officecli validate 보고서.docx` | 파일 구조 검사 |
| `officecli watch 발표.pptx` | 만드는 중 브라우저 미리보기 |

### PMO 예시 요청
```
officecli로 주간보고_서식.docx 를 merge 해서 이번 주 보고서를 만들어 줘.
값은 1_정리.json 에서 가져와. 만든 뒤 validate 하고 outline 을 보여 줘.
```

### 주의
- 원래 **부동산 관리 회사 제품(AscendOps)**용 스킬이라 예시가 "임대인 월간 보고서, 작업 지시서"입니다. 자동 호출 단어도 그 업무에 맞춰져 있으니 **"officecli로"라고 이름을 불러** 쓰세요.
- 인터넷에서 **실행 파일을 받는** 방식이라 출처 확인(공식 릴리스, 버전 고정)이 필요합니다.

## 4. Office Docs — 파이썬 코드로 직접 만들기

### 추가 설치
- `uv` 설치 (윈도우: `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"` 또는 기관 승인 설치본)
- 스킬 폴더의 `scripts\make_pptx.py`, `make_xlsx.py`, `make_docx.py` (예제 틀)가 함께 있어야 함

### 동작 방식
1. AI가 예제 틀을 복사해 **작은 생성 스크립트**를 씀
2. `uv run --with python-docx python make.py` 처럼 실행 (필요한 도구를 그때그때 받아 씀)
3. PPT는 PDF→그림으로 바꿔 **눈으로 확인**, 엑셀·워드는 행·도형 수를 세어 확인
4. 맞을 때까지 고친 뒤 **최종 파일 이름으로 저장**

### 한국어로 쓸 때 꼭 이름 부르기
이 스킬의 자동 호출 단어는 **네덜란드어**("maak een powerpoint")입니다. 한국어 요청으로는 잘 안 켜지므로:
```
office-docs 스킬로 이슈대장 엑셀을 만들어 줘.
열: 번호, 내용, 영향도, 담당, 기한, 상태
첫 행 고정, 필터, 상태 열은 열림/조치중/종료 드롭다운, 높음은 빨간 글씨.
가로 인쇄, 한 페이지 너비에 맞춤. 글꼴은 맑은 고딕.
```

### 원문에 적힌 실전 함정 (실제로 겪은 것)
| 함정 | 해결 |
|---|---|
| 엑셀·워드가 **열려 있으면 저장 실패**(PermissionError) | 작업 중엔 `_work.xlsx`로 저장, 끝나면 최종 이름. 또는 파일을 닫고 실행 |
| 경로에 공백 | 따옴표로 감싸기 |
| 없는 글꼴은 다른 글꼴로 바뀜 | **한글은 "맑은 고딕"으로 지정** (원문 추천 Calibri는 한글 없음) |
| 엑셀 줄바꿈 셀이 잘림 | 행 높이를 계산해서 지정 |
| PPT 도형마다 기본 그림자 | 효과 목록을 비워 그림자 제거 |

## 6. 공통 안전 수칙
- 업무 서식·자료는 **사본으로** 작업하고 결과는 별도 폴더에
- 만든 문서는 **사람이 열어서 확인** (AI의 "검증 완료"는 구조 검사일 뿐, 내용 정확성 보증 아님)
- 남이 만든 SKILL.md는 **설치 전에 한 번 읽기** (숨은 지시, 외부 전송 여부)
- 업무 자료를 클라우드 AI에 넣는 것이 **기관 규정상 허용되는지** 먼저 확인
