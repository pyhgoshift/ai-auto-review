# 윈도우 부팅 직후부터: 오피스 스킬로 문서 만들기

> 기준: 윈도우 11, 개인 PC, 인터넷 연결, Claude 유료 요금제(Pro 이상 — 무료 요금제는 Claude Code 사용 불가)
> 설치 방법 출처: Claude Code 공식 문서 (code.claude.com/docs/en/setup, /skills) — 2026-11-22 확인
> ⚠️ 공단 업무 PC·업무 자료에는 쓰지 마세요. 연습은 **개인 PC + 가상 자료**로.

전체 흐름 (약 40분)
```
① PowerShell 열기 → ② Git 설치 → ③ Claude Code 설치 → ④ uv 설치 → ⑤ LibreOffice 설치
→ ⑥ 작업 폴더 → ⑦ 스킬 넣기 → ⑧ Claude Code 실행·로그인 → ⑨ 첫 문서 만들기 → ⑩ 결과 확인
```

---

## ① PowerShell 열기
| | |
|---|---|
| **언제** | 지금, 맨 처음 한 번 |
| **어디서** | 화면 아래 **시작 버튼(윈도우 로고)** |
| **무엇을** | 명령을 입력하는 창(PowerShell) 열기 |
| **어떻게** | 시작 버튼 → `powershell` 입력 → **Windows PowerShell** 클릭 (관리자 권한 필요 없음) |
| **확인** | 파란/검은 창에 `PS C:\Users\사용자이름>` 이 보이면 성공 |

> 이후 모든 명령은 이 창에 **복사 → 붙여넣기(마우스 오른쪽 클릭) → Enter** 입니다.

## ② Git 설치 (Claude Code가 명령을 잘 실행하게 해 주는 도구)
| | |
|---|---|
| **언제** | ①번 직후 |
| **어디서** | PowerShell 창 |
| **무엇을** | Git for Windows 설치 (공식 문서 권장, 필수는 아님) |
| **어떻게** | 아래 명령 입력. 설치 창이 뜨면 **기본값으로 Next** |
| **확인** | **PowerShell 창을 닫고 새로 연 뒤** `git --version` → `git version 2.xx` |

```powershell
winget install --id Git.Git -e
```

## ③ Claude Code 설치
| | |
|---|---|
| **언제** | ②번 직후 |
| **어디서** | (새로 연) PowerShell 창 |
| **무엇을** | Claude Code 설치 (Node.js 필요 없음) |
| **어떻게** | 아래 명령 입력 |
| **확인** | 창을 새로 열고 `claude --version` → `2.x.x (Claude Code)` |

```powershell
irm https://claude.ai/install.ps1 | iex
```
- `claude`를 못 찾는다고 나오면: 창을 닫고 새로 열기. 그래도 안 되면 `$env:USERPROFILE\.local\bin` 을 사용자 PATH에 추가
- "스크립트를 실행할 수 없습니다(running scripts is disabled)" 오류가 나면:
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```

## ④ uv 설치 (파이썬 도구를 알아서 받아 실행해 주는 프로그램)
| | |
|---|---|
| **언제** | ③번 직후 |
| **무엇을** | 스킬 4번(Office Docs)과 문서 생성 코드 실행용 |
| **어떻게** | 아래 명령 |
| **확인** | 창 새로 열고 `uv --version` |

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

## ⑤ LibreOffice 설치 (만든 문서를 PDF로 바꿔 **AI가 눈으로 확인**하는 데 씀)
| | |
|---|---|
| **언제** | ④번 직후 (약 5분) |
| **어떻게** | 아래 명령, 설치 창은 기본값 |
| **확인** | `& "C:\Program Files\LibreOffice\program\soffice.exe" --version` |

```powershell
winget install --id TheDocumentFoundation.LibreOffice -e
```

## ⑥ 작업 폴더 만들기
| | |
|---|---|
| **어디서** | PowerShell |
| **무엇을** | 문서가 만들어질 폴더 `C:\PMO-AI` |

```powershell
mkdir C:\PMO-AI
cd C:\PMO-AI
```

연습용 가상 자료(28번 PMO 팀의 서식·가상 원자료)를 받으려면:
```powershell
git clone -b claude/phone-timacs-server-access-nqz4m6 https://github.com/pyhgoshift/ai-auto-review.git 연습자료
```
- 저장소가 비공개면 이 단계에서 GitHub 로그인 창이 뜹니다. 로그인하면 됩니다.

## ⑦ 스킬 넣기 (모든 프로젝트에서 쓰는 "개인 스킬" 폴더에)
| | |
|---|---|
| **어디에** | `C:\Users\사용자이름\.claude\skills\스킬이름\SKILL.md` |
| **무엇을** | 추천 순서: **4번 Office Docs → 1번 Office Agent**. 2번은 건너뜀, 3번은 선택 |

**4번 Office Docs (가장 간단, 먼저)**
```powershell
git clone https://github.com/robinbril/claude-code-harness.git C:\PMO-AI\_src\harness
mkdir $env:USERPROFILE\.claude\skills -Force
Copy-Item -Recurse C:\PMO-AI\_src\harness\skills\office-docs $env:USERPROFILE\.claude\skills\office-docs
```

**1번 Office Agent (종합형)**
```powershell
git clone https://github.com/Harshuqt/office-agent-skills.git C:\PMO-AI\_src\office-agent-skills
Copy-Item -Recurse C:\PMO-AI\_src\office-agent-skills\skills\office-agent $env:USERPROFILE\.claude\skills\office-agent
```
- 이 스킬은 저장소 안의 **전용 파이썬 환경(.venv)**이 있어야 동작합니다. 저장소 README의 **설치(setup) 안내를 한 번 실행**하세요. 직접 하기 어려우면 ⑧번 이후 Claude Code에게 "`C:\PMO-AI\_src\office-agent-skills` README대로 설치해 줘"라고 시켜도 됩니다(실행 전 명령을 보여 주고 허락을 구합니다).

**3번 OfficeCLI (선택)**: 원문 설치 명령이 맥 전용이라, 윈도우에서는 OfficeCLI 공식 릴리스의 **윈도우용 파일**을 받아야 합니다. 처음에는 건너뛰기를 권합니다.

**2번 Office Productivity**: 다른 스킬 15개가 필요한 목차형이라 **설치하지 않습니다.**

## ⑧ Claude Code 실행·로그인
| | |
|---|---|
| **언제** | 스킬을 넣은 뒤 |
| **어디서** | PowerShell, `C:\PMO-AI` 폴더에서 |
| **어떻게** | `claude` 입력 → 처음이면 **브라우저가 열려 로그인** → 다시 창으로 |
| **확인** | 입력창에서 `/skills` 입력 → 목록에 `office-docs`, `office-agent`가 보이면 성공. 안 보이면 `/reload-skills` |

```powershell
cd C:\PMO-AI
claude
```

## ⑨ 첫 문서 만들기 (Claude Code 입력창에 그대로 붙여넣기)
| | |
|---|---|
| **언제** | ⑧번에서 스킬 확인 후 |
| **어디서** | Claude Code 입력창 (`>` 표시) |
| **무엇을** | 엑셀 → 워드 → PPT 순서로 하나씩 |
| **어떻게** | 아래 문장을 붙여넣기. 명령 실행 허락을 물으면 내용을 보고 **Yes** |

**엑셀 (4번 Office Docs)**
```
/office-docs 이슈대장 엑셀을 C:\PMO-AI\출력\이슈대장.xlsx 로 만들어 줘.
자료는 C:\PMO-AI\연습자료\pmo-ai-team\samples\가상_원자료_예시.txt 에서 이슈와 리스크만 뽑아.
열: 번호, 구분, 내용, 영향도, 담당, 기한, 상태. 첫 행 고정, 필터,
상태는 열림/조치중/종료 드롭다운, 영향도 높음은 빨간 글씨, 가로 인쇄, 글꼴은 맑은 고딕.
원자료에 없는 값은 비워 두고 지어내지 마.
```

**워드 (1번 Office Agent)**
```
/office-agent 주간보고 워드 문서를 만들어 줘.
서식은 C:\PMO-AI\연습자료\pmo-ai-team\templates\주간보고_서식.md 순서를 따르고,
내용은 C:\PMO-AI\연습자료\pmo-ai-team\results\예시_최종초안.md 를 그대로 옮겨.
결과는 outputs 폴더에, PDF로 렌더링해서 표가 잘리지 않았는지 확인해.
```

**PPT (1번 Office Agent)**
```
/office-agent 방금 만든 주간보고로 5장짜리 발표자료를 만들어 줘.
표지, 진척률, 이슈, 리스크, 다음 주 계획. 슬라이드를 그림으로 렌더링해서 글자 넘침이 없는지 확인해.
```

## ⑩ 결과 확인
| | |
|---|---|
| **어디서** | 파일 탐색기 → `C:\PMO-AI\출력` 또는 `outputs` |
| **무엇을** | 파일을 직접 열어 **숫자·날짜·이름**을 원자료와 대조 |
| **주의** | 엑셀·워드를 **열어 둔 채로** 다시 시키면 저장 실패 → 파일을 닫고 다시 요청 |

## 막혔을 때
| 증상 | 해결 |
|---|---|
| `winget`이 없다고 나옴 | Microsoft Store에서 **앱 설치 관리자(App Installer)** 업데이트 |
| `claude` 명령을 못 찾음 | 창 새로 열기 → 그래도 안 되면 `claude doctor`, PATH에 `%USERPROFILE%\.local\bin` 추가 |
| `/skills`에 스킬이 안 보임 | 폴더 위치 확인: `dir $env:USERPROFILE\.claude\skills\*\SKILL.md` → `/reload-skills` |
| 한글이 깨짐 | 요청에 "글꼴은 맑은 고딕"을 넣기 |
| AI가 엉뚱한 스킬을 씀 | `/office-docs …`처럼 **스킬 이름을 앞에** 붙여 부르기 |
| 무료 요금제 | Claude Code는 Pro 이상 필요 |
