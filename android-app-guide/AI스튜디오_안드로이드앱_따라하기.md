# 코딩 없이 내 폰 전용 안드로이드 앱 만들기 (Google AI Studio + USB 설치)

> 기준: 윈도우 PC + 안드로이드 폰 (2026-11-22 공식 문서 확인)
> 공식 문서: ai.google.dev/gemini-api/docs/aistudio-android
> 방식: AI Studio에서 앱 생성 → 브라우저 에뮬레이터로 시험 → **USB 케이블로 내 폰에 직접 설치** (지역 제한 없음, 개발자 등록비 없음)

## 준비물 체크
- [ ] 윈도우 PC + **Chrome 또는 Edge** 브라우저
- [ ] **안드로이드 7.0 이상** 폰 (갤럭시 대부분 해당)
- [ ] **데이터 전송이 되는 USB 케이블** (충전 전용 케이블은 안 됨. 폰을 살 때 들어 있던 케이블 권장)
- [ ] Google 계정

---

## 1단계. 폰에서 "개발자 옵션" 켜기 (처음 한 번만, 약 2분)
| | |
|---|---|
| **어디서** | 폰의 **설정** 앱 |
| **어떻게 (갤럭시)** | 설정 → **휴대전화 정보** → **소프트웨어 정보** → **빌드번호**를 **7번 연속 톡톡** → 잠금 비밀번호 입력 |
| **확인** | "개발자 모드를 켰습니다" 알림 |

> 다른 폰: 설정 → 휴대전화 정보 → 빌드 번호 7번 탭 (메뉴 이름만 조금 다름)

## 2단계. 폰에서 "USB 디버깅" 켜기
| | |
|---|---|
| **어디서** | 설정 → 맨 아래 **개발자 옵션** (새로 생김) |
| **어떻게** | **USB 디버깅** 스위치 켜기 → "허용" |
| **왜** | PC가 폰에 앱을 설치할 수 있게 문을 열어 주는 설정 |

## 3단계. PC에서 AI Studio 열기
| | |
|---|---|
| **어디서** | 윈도우 → **Chrome**(또는 Edge) 실행 |
| **어떻게** | 주소창에 `aistudio.google.com` → Google 계정으로 로그인 |
| **확인** | 왼쪽 메뉴에 **Build** 가 보임 |

## 4단계. 안드로이드 앱 만들기
| | |
|---|---|
| **어디서** | 왼쪽 메뉴 **Build** |
| **어떻게** | 플랫폼 선택에서 **Android** 선택 → 입력창에 만들 앱을 한국어로 설명 → 실행 |
| **기다림** | 몇 분. AI가 코드를 만들고 화면 오른쪽에 **미리보기(에뮬레이터)**가 뜸 |

**처음 만들기 좋은 예시 (그대로 붙여넣기)**
```
안드로이드 앱을 만들어 줘. 이름은 "오늘 할 일 3개".
- 첫 화면에 오늘 할 일을 최대 3개까지 입력하는 칸
- 각 항목 옆에 완료 체크 버튼, 완료하면 줄 긋기
- 앱을 껐다 켜도 내용이 남아 있게 폰 안에 저장
- 글자는 크게, 버튼은 엄지로 누르기 쉽게
- 화면 문구는 모두 한국어
- 로그인, 인터넷 연결, 광고는 넣지 마
```
> 처음에는 **간단한 앱**으로 시작하세요. 공식 문서 기준 AI Studio의 안드로이드 앱은 **폰 안에서만 도는 앱**(서버 없음)이고, 로그인 기능 등 일부는 아직 지원이 제한됩니다.

## 5단계. 브라우저에서 먼저 시험
| | |
|---|---|
| **어디서** | 오른쪽 **미리보기 에뮬레이터** (화면 속 가짜 폰) |
| **어떻게** | 마우스로 눌러 보며 동작 확인 |
| **고치고 싶으면** | 왼쪽 입력창에 "체크하면 초록색으로 바꿔 줘"처럼 말로 요청 → 다시 시험 |

## 6단계. 폰을 PC에 연결
| | |
|---|---|
| **어떻게** | USB 케이블로 폰과 PC 연결 → 폰 잠금 해제 |
| **폰 화면에 뜨면** | "USB 디버깅을 허용하시겠습니까?" → **"이 컴퓨터에서 항상 허용"** 체크 → **허용** |
| **USB 연결 방식을 물으면** | **파일 전송** 선택 |

## 7단계. 폰에 설치 ★
| | |
|---|---|
| **어디서** | AI Studio 미리보기 영역의 **Install on Device** 버튼 |
| **어떻게** | 버튼 클릭 → 브라우저에 **장치 선택 창**이 뜸 → 내 폰 이름 선택 → **연결** |
| **결과** | 앱이 폰으로 전송·설치되고 **자동으로 실행됨** |
| **확인** | 폰 앱 목록에 새 앱 아이콘 |

## 8단계. 백업 (선택, 권장)
| | |
|---|---|
| **왜** | AI Studio 프로젝트가 사라지거나 바뀌어도 원본을 남기기 위해 |
| **어떻게** | 프로젝트를 **ZIP으로 내려받기** (또는 GitHub로 내보내기) → PC에 보관 |

## 9단계. 끝나면 보안 정리
- 폰: 설정 → 개발자 옵션 → **USB 디버깅 끄기** (평소엔 꺼 두는 게 안전)
- 다시 설치할 때만 2단계처럼 켜면 됨

---

## 막혔을 때
| 증상 | 해결 |
|---|---|
| 7단계 장치 선택 창에 **폰이 안 보임** | ① 케이블을 데이터용으로 교체 ② 폰 잠금 해제 상태 확인 ③ USB 방식 "파일 전송" ④ 다른 USB 포트 ⑤ Chrome ↔ Edge 바꿔 보기 |
| 폰이 보이는데 연결 실패 | PC에서 **삼성 스마트 스위치, 다른 폰 관리 프로그램**을 끄기 (폰 연결을 먼저 차지함) → 케이블 뺐다 다시 꽂기 |
| 갤럭시인데 계속 안 됨 | 삼성 공식 **USB 드라이버** 설치 후 PC 재시작 |
| "USB 디버깅 허용" 창이 안 뜸 | 개발자 옵션 → **USB 디버깅 권한 승인 취소** → 케이블 다시 연결 |
| Install on Device 버튼이 없음 | 플랫폼이 **Android**로 만들어진 프로젝트인지 확인 (웹앱 프로젝트에는 없음) |
| 앱이 이상하게 동작 | 5단계로 돌아가 말로 수정 요청 → 7단계로 다시 설치 (덮어써짐) |

## 알아 둘 점
- 이 앱은 **내 폰에서만 쓰는 개인용**입니다. Google Play 스토어에 공개되지 않습니다.
- 다른 사람에게 배포하려면 **Google Play 개발자 계정(등록비 25달러)**이 필요합니다(내부 테스트 배포).
- "개인 앱을 Google Play 보관함으로 보내기"는 **공식 기능**입니다(Google Play 도움말, 2026-10-13 발표). 단 **미국 거주 + 18세 이상 연령 인증 계정**만 가능해 한국에서는 쓸 수 없고, 그래서 이 안내는 USB 설치를 씁니다. 출처: support.google.com/googleplay/answer/18936837
- 앱에 **개인정보·업무 자료를 넣지 마세요.** 처음엔 연습용으로.
